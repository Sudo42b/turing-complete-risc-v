# 12-fpu-d — D 확장 (배정도)

## 목적

IEEE-754 binary64 연산 32종. 11-fpu-f 의 하위 모듈을 부호 1, 지수 11, 가수 53(숨은 1 포함) 폭으로 다시 만든다.
fcvt.s.d / fcvt.d.s 로 두 정밀도를 오간다.

## F 와 다른 점

| 항목 | F | D | 영향 |
|---|---|---|---|
| 가수 곱 | 24×24 = 48비트 | 53×53 = 106비트 | `Mul(64)` 하나로 안 됨. 27비트×2 로 나눈 부분곱 4개(각 54비트) 와 캐리 처리, 08-muldiv 의 mulhu 와 같은 구조 |
| 나눗셈 | (가수<<26)/가수 가  64비트 안에 들어감 | (가수<<55) 가 108비트 | `Div(64)` 한 번으로 불가. 상위 워드 나눗셈 후 나머지를 이어 붙이는 2단계 장제법, 또는 복원 나눗셈 55단계 조합 체인 |
| 제곱근 | 26단계 | 55단계 | 조합 체인 길이 2배 |
| FMA 정확 폭 | 74비트 | 161비트 | 64비트 부품 3개로 분할. 첫 구현은 비융합 |
| 정렬 시프트 | 최대 ~50 | 최대 ~110 | Lsr(64) 두 단계(워드 선택 + 비트 시프트) |
| NaN-boxing | 상위 32비트 1 | 해당 없음 | D 값은 64비트 그대로 |

## 하위 모듈

`RV64G/D_Unpack`, `D_Pack`, `D_Round`, `D_AddSub`, `D_Mul`, `D_Div`, `D_Sqrt`, `D_FMA`, `D_Cmp`, `D_Cvt`, `D_Misc`, 그리고 `D_FromS`/`D_ToS`(fcvt.d.s / fcvt.s.d: 지수 재바이어스 + 가수 시프트 + 반올림).
FRegFile 은 11-fpu-f 것을 그대로 쓴다.

## 보드 공간

D 연산기가 가장 크다. 샌드박스 보드 한도(B11)에 걸리면 D_Mul/D_Div/D_Sqrt/D_FMA 를 각각 파운드리 부품으로 캡슐화하고
상위 보드에는 인스턴스만 둔다. 파운드리 부품 중첩이 몇 단계까지 되는지도 B11 에서 확인.

## 구현 순서

1. D_Unpack/Pack/Misc, fld/fsd, D_Cmp, D_FromS/D_ToS
2. D_Round, D_AddSub
3. D_Mul (부분곱 4개)
4. D_Cvt
5. D_Div, D_Sqrt
6. D_FMA

## 검증

- 1.0 = 0x3FF0_0000_0000_0000, 0.1 + 0.2 = 0x3FD3_3333_3333_3334
- 1.0 / 3.0 = 0x3FD5_5555_5555_5555
- sqrt(2.0) = 0x3FF6_A09E_667F_3BCD
- fcvt.s.d(0.1) = 0x3DCCCCCD, fcvt.d.s(0.1f) = 0x3FB9_9999_A000_0000
- 참조값: `struct.unpack('<Q', struct.pack('<d', v))`
